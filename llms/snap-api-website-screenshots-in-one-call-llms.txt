## API

Endpoint: GET https://snap.flyhold.in/v1/take

Query parameters:
- api_key (required unless using a header) — from the dashboard after signup
- url (required) — target page, https preferred
- width — viewport width in px (e.g. 1280)
- height — viewport height in px (e.g. 720)
- file_type — png | jpeg | webp | pdf (default png)
- block_cookie_banners — true | false (recommend true)
- cache — omit for ≤1h render cache; cache=false to bypass (HIT does not burn a credit)

Auth (any one): query `api_key` **or** header `X-API-Key` **or** `Authorization: Bearer <key>`.

Response: binary file (image/png, image/jpeg, image/webp, or application/pdf). Response header `X-Snap-Cache: HIT|MISS|BYPASS`. For n8n, set Response format to File and timeout to 60 seconds.

Example:

```
curl -G "https://snap.flyhold.in/v1/take" \
  --data-urlencode "api_key=YOUR_API_KEY" \
  --data-urlencode "url=https://example.com" \
  --data-urlencode "width=1280" \
  --data-urlencode "height=720" \
  --data-urlencode "file_type=png" \
  --data-urlencode "block_cookie_banners=true" \
  --max-time 60 \
  -o shot.png
```
